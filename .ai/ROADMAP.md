# IWOS Specification Roadmap

**Version:** 1.0.0  
**Status:** Active  
**Authority:** Planning artifact derived from approved work packages  
**Last Updated:** 2026-07-31

## Phase 0 — Repository Foundation

Establish the constitutional repository structure, AI onboarding context, and engineering memory.

### Outcomes

- Ratified charter and architecture baseline are present.
- AI agent contract is available.
- `.ai/` operational memory exists.
- Work packages are tracked.

## Phase 1 — Governance Completion

Create governance documents, contribution rules, review standards, and change-control procedures.

### Outcomes

- Governance directory populated.
- Engineering constitution available.
- Review and documentation workflows documented.
- Decision record process formalized.

## Phase 2 — Architecture Specification Expansion

Develop architecture, standards, schemas, templates, examples, ADRs, and AIPs in alignment with the ratified baseline.

### Outcomes

- Architecture layer specifications are documented.
- Schema contracts are versioned.
- Templates enable consistent future work.
- ADR/AIP indices support traceability.

## Phase 3 — Ecosystem Readiness

Prepare the specification repository to guide downstream implementation repositories.

### Outcomes

- Bootstrap instructions are complete.
- Cross-repository relationship is explicit.
- Compliance checks are documented.
- Engineering state is maintained after each work package.
