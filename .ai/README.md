## Purpose

The `.ai/` workspace is the engineering memory of the IWOS specification repository. The Architecture Baseline requires engineering state to be machine-readable and engineering memory to be updated after every completed activity; the AI Agent Contract names the records that must be updated. This directory holds those records.

Nothing here carries authority. These files summarise and index the ratified documents so that a human or agent can reconstruct context quickly. Where a memory file and a ratified document disagree, the ratified document is correct and the memory file is updated.

## Update Rules

1. Memory must be updated in the same change that completes the activity it records.
2. `CONSTITUTION_LOCK.yaml` must be regenerated only when a protected document changes under an accepted proposal. The validator fails when the lock and the protected documents disagree.
3. Every decision in `DECISION_GRAPH.yaml` must name its authority and the files it affects. Architectural decisions are recorded in `adr/` instead and referenced from the decision graph.
4. Every node in `KNOWLEDGE_GRAPH.yaml` that names a path must point at a file that exists. The validator checks this.
5. `NEXT_TASK.md` must name exactly one recommended next task.
