## Purpose

AIP-0002 proposes that the programme's first specified components are the Verification Engine and Decision Ledger in the domain of AI-assisted engineering, and authorises a reference toolchain. This package authorises building that toolchain, provisionally named IWOS Guard, so that any repository can declare a constitution, lock its protected documents, gate agent pull requests, and let any agent ask for authority before acting.

The repository owner accepted the strategic direction on 2026-11-09 and accepted AIP-0002 on 2026-11-10, whose Specification item 3 authorises this package. Its status is therefore Approved.

## Objective

A repository can run `iwos init`, `iwos validate`, `iwos lock`, `iwos gate` and `iwos mcp` against itself, and this repository passes its own gate on every pull request.

## Scope

- `tools/iwos/`: the Python package, its tests and README.
- `action.yml`: composite GitHub Action at the repository root.
- `iwos.yaml`: this repository's constitution file, `iwos-spec` profile.
- `schemas/iwos-config.schema.json`, bindings and examples.
- `.github/workflows/validate.yml`: run the toolchain's tests and the gate.
- `AGENTS.md`: a generated block maintained by `iwos agents`.
- `README.md`: a quickstart for the toolchain.
- Engineering memory and change log.

## Non-Scope

- Any change to a protected document. Project Genesis changes only when AIP-0002 is accepted, by the Constitutional Authority.
- Any product runtime code, hosted service or network listener.
- A dedicated repository for the toolchain (ADR-0004 defers it).

## Outputs

| Output | Path | Acceptance |
| --- | --- | --- |

| Dogfood | `.github/workflows/validate.yml` | This repository passes `iwos validate` and `iwos gate` in continuous integration. |

## Validation Criteria

- `make validate` and `make test` pass.
- `iwos validate` passes against this repository; `iwos gate` passes on this package's own pull request.
- A deliberate change to a protected document without a citation fails `iwos gate`.
- No protected document differs from `main`.
