## Purpose

This register lists every Request for Comments (RFC) raised in the IWOS specification repository and allocates RFC identifiers. An RFC is the first, exploratory step of the Decision Process. It is non-binding.

## Raising an RFC

1. Copy `templates/rfc-template.md` to `governance/rfc/RFC-####.md` using the next identifier in this register.
2. Complete every section. State the question, the constraints, the options known so far and the feedback requested.
3. Open a pull request. Alternatively, open an issue with the RFC form in `.github/ISSUE_TEMPLATE/`; a Maintainer converts a substantive issue into a file here.
4. Keep the RFC open for at least five working days.
5. A Maintainer closes the RFC and records its disposition: `Closed`, `Converted` (to an AIP, ADR, standard or work package, which is named) or `Withdrawn`.
